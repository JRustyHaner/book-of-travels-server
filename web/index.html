Braid

A private Book of Travels server — self-hosted by the community, after the official servers closed.

What this is

Braid runs an independent server for Book of Travels (by Might & Delight), restoring online play after the official servers shut down. It is a community project: not affiliated with or endorsed by the developers. Modding is officially permitted by the developers, and self-hosted servers were left to the modding community.

You need your own copy of Book of Travels on Steam. The server never ships or hosts game files — this page only installs a mod into your install.

Server

Master serverbraid.flightlessbirdlabs.io:1234 (accounts, rooms)
Game serverbraid.flightlessbirdlabs.io:50050 (the world)
Players per instanceup to 16

Windows setup

In PowerShell (run as the account that owns the game):

Set-ExecutionPolicy -Scope Process Bypass
Invoke-WebRequest -Uri "https://github.com/JRustyHaner/book-of-travels-server/releases/latest/download/setup-client.ps1" -OutFile setup-client.ps1
.\setup-client.ps1

The script finds your Steam install, installs BepInEx + the mod, and writes the server config. Then launch the game normally from Steam. Log in with any email + password — accounts are created automatically.

Linux setup

curl -fsSL "https://github.com/JRustyHaner/book-of-travels-server/releases/latest/download/setup-client.sh" -o setup-client.sh
bash setup-client.sh

Then launch through the mod (the script prints the exact command, or use the Steam launch options it suggests).

Playing with friends

  1. Everyone installs the mod (above) and logs in with their own email/password.
  2. Characters are saved on the server — the world persists between sessions.
  3. The world layout is randomized per server (as the game intended).

Removing the mod

Delete the files the script reports, or in Steam: right-click the game → Properties → Installed Files → Verify integrity of game files. No game files are ever modified.

FAQ

Is this allowed? The developers officially permit mods and pointed the community at self-hosted servers. You must own the game. Use at your own risk.
Why can't I connect? Make sure the master port 1234 and game port 50050 are reachable, and that your client config points at braid.flightlessbirdlabs.io.
Note: the game's network traffic is unencrypted. Play on trusted networks.
